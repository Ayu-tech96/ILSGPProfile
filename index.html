GP antenna system types
Null Reference (0-Ref)
2 elements. Lower = CSB+SBO, Upper = SBO only.
h_L = λ/(4sinθ)
h_U = 2·h_L = λ/(2sinθ)
Ground plane: ~800 m
Sites: level terrain, simple
CAT I typical
NF formula: h_L·(h_L+h_U) / λ
Monitor at θ elevation
Sideband Reference (SB-Ref)
2 elements. Lower = CSB+SBO (anti-phase), Upper = SBO.
h_L = λ/(8sinθ)
h_U = 3·h_L = 3λ/(8sinθ)
Ground plane: ~700 m
Sites: descending terrain toward THR
NF formula: h_L·(h_L+h_U) / λ
Monitor at 2θ elevation
M-Array / Capture Effect
3 elements. Lower SBO, Middle CSB, Upper SBO.
h₁ = λ/(4sinθ) h₂ = 2h₁
h₃ = 3h₁
Ground plane: ~550 m
Sites: most terrain, CAT II/III
NF formula: h₁·(h₁+h₃) / λ
Monitor at θ elevation
Formula reference — ICAO Annex 10 / Qu 2018
NF monitor distance
DNF = hlo × (hlo + hhi) / λ
360° phase-error point. Pattern inversion occurs here. NF monitor antenna is physically installed at this distance from the mast. (Ref: Qu 2018, SCIRP OJAPR)
NF monitor antenna height
hNF = DNF × tan θ  [NR, M-Array]
hNF = DNF × tan 2θ  [SB-Ref]
Mount height of the NF monitor antenna above local ground at the DNF position. SB-Ref monitors at twice the glide angle elevation.
RDH / TCH — Reference Datum Height
RDH = (Zmast + hlo − Zthr) + d × tan θ
Height of GP centreline above the runway threshold. Zmast = mast ground elev., Zthr = THR ground elev., d = longitudinal offset. ICAO standard: 15 m ± 3 m (50 ft ± 10 ft).
Correction for RDH = 15 m
dreq = (15 − Zmast − hlo + Zthr) / tan θ
latreq = lat + (15 − RDH) / SSL
Two independent solutions: adjust longitudinal distance d from THR, or adjust lateral distance from C/L using sideways slope SSL. Actual values shown in Results after analysis.
